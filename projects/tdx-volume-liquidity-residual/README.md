# 通达信量价流动性残差模型

> Volume-Liquidity Residual Model for TongDaXin (TDX)

## 项目定位

本项目实现一个“成交量条件下的价格冲击异常”模型：

- 用历史相对成交量解释正常真实波幅；
- 当前K线不参与自己的基准、回归与残差标准化；
- 正残差表示价格冲击高于当前成交量条件下的历史预期；
- 负残差 + 明显放量表示大量成交未产生应有价格位移，作为吸收候选；
- 强扩事件进一步用 60/20/10 日窗口做活跃度分层，而不是简单认为次数越多越好。

当前稳定实验版本：**V2.1.2**

## 核心信号

| 信号 | 条件摘要 | 解释 |
|---|---|---|
| 真空↑ / 真空↓ | Z > +1.5，方向明确，RVOL < 1.20 | 非明显放量却出现异常价格冲击 |
| 强扩↑ / 强扩↓ | Z > +1.5，方向明确，RVOL >= 1.20 | 放量后价格冲击仍显著高于历史预期 |
| 吸收多 / 吸收空 | Z < -1.5，RVOL > 1.50，DIR 与 CLV 同向 | 大量成交未形成应有位移，观察承接/压制 |

## V2.1.2 关键设计

1. **滞后基准**：ATR、成交量基准只使用前一根K线以前的数据。
2. **样本外检测**：当前K线不参与当前滚动 OLS。
3. **滞后残差标准化**：当前残差不参与自己的均值和标准差。
4. **稳健训练**：RVOL/MOV 训练样本截尾，但当前异常检测保留原始值。
5. **正斜率约束**：量价正常关系的 OLS 斜率约束为非负。
6. **R²双指标**：
   - R2RAW = RHO²，保留正负相关的原始线性强度；
   - R2POS = max(RHO,0)²，反映符合正斜率假设的有效关系强度。
7. **方向三因子**：DR（昨收至今收位移）+ DB（实体方向）+ CLV（收盘位置），权重可调并自动归一化。
8. **量能梯度**：
   - RVVAC = 1.20；
   - RVTH = 1.50。
9. **事件去重**：COOL=3，连续强扩不会机械重复计数。
10. **活跃度分层**：区分沉寂、预热、健康活跃、高活跃、持续高活跃、过热密集。

## 强扩活跃度分层

- **QUIET**：60日 0–1 次
- **WARMUP**：60日 2 次，且10日内至少1次
- **ACTIVE**：60日 3–4 次，10日 1–2 次，且未过热
- **HIGHACT**：60日 5–6 次，10日 1–2 次，且未过热
- **LONGACT**：60日 >=7 次，但近期仍保持合理节奏
- **HOT**：10日 >=3 次，或20日 >=4 次

默认分层选股使用：

```text
XG:ACTIVE OR HIGHACT;
```

## 建议测试方法

不要先做参数优化。建议先固定参数，在不同市场状态与不同股票池上分别统计：

- 信号后 1/3/5/10/20 日收益；
- 胜率；
- 最大有利波动（MFE）；
- 最大不利波动（MAE）；
- ACTIVE / HIGHACT / LONGACT / HOT 各层后效差异；
- RHO、R2RAW、R2POS 分层后的表现。
